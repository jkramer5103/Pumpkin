# Initial Ender Dragon circling direction

A new dragon starts with the wrong orbit direction. In an isolated, crystal-free arena at `(40,160,0)`, vanilla turns by −1.5735644° on its first circling tick; the pre-patch Pumpkin turns by −3.5°. Its horizontal displacement and velocity differ too. Four fresh dragons and four dragons with nodes initialized while hovering reproduce the difference without simultaneous boss contact.

Initialize `holding_pattern_clockwise` to false. Vanilla 26.3 `DragonHoldingPatternPhase.clockwise` has Java's implicit false default; its constructor and `begin()` never overwrite it. Pumpkin's existing direction toggles and phase persistence remain intact. At middle-ring node 12 in this arena, vanilla's ordinary decrement and its optional reversal (`+6`, then increment) both select node 19 after eight-node wrapping. This permits a bounded first-route comparison despite random reversal and waypoint height.

The fixture `lab/examples/dragon-initial-circling-direction.json` and checker `tests/check_dragon_initial_circling_direction.py` cover first-turn yaw, horizontal position/velocity, vertical movement, phase retention, pre-tick position/motion, NoAI, exact stepped ticks and cleanup. Each dragon is removed before the next case. The checker compares numeric data, avoiding unrelated SNBT decimal formatting differences.

Validation: 489 `pumpkin-core` library tests, workspace formatting, core all-targets/all-features Clippy and debug server build passed under the shared Cargo lock and resource limits. The identical final arena passed 73/73 checks on vanilla and patched Pumpkin; baseline passed 49/73, failing exactly eight yaw, eight horizontal movement and eight horizontal velocity checks. Each target advanced 18 controlled ticks. Source/fixture/stimulus/copied-binary hashes, connected headless clients, cleanup and stopped scratch servers were verified. Both Pumpkin servers completed saving; no server/client errors or panics were found. Vanilla final-save completion was not confirmed within the shutdown grace period. The exploratory fixture with textual position controls is excluded.

The turn is −1.5735601° after the patch, versus vanilla −1.5735644°. Existing numerical steering differences remain: the checker allows 0.00001° yaw and 0.000005 blocks for horizontal position/velocity. Baseline differs by about 1.9° and 0.002 blocks and fails all 24 affected checks. Vertical checks use a separate 1e-10 tolerance. This fixture is focused gameplay regression coverage; no new constructor-only Rust unit test was added. Local evidence: `artifacts/christine-dragon55-rust-validation.json`, `artifacts/christine-dragon55-live-validation.json`, and `artifacts/christine-dragon55-source-provenance.json`.

Fork master was fetched and is already included. Current read-only upstream master `fb7c8e223a387b9658c72eca620c81382dc66f07` still initializes the direction true. Open PR searches and current file patches for #3407, #3661 and #3835 show no change to circling direction; multipart/crystal/projectile work remains deferred to those PRs. The tracker and mob AI issue #3468 were checked as leads, with prior contact-gate fixes left intact.
