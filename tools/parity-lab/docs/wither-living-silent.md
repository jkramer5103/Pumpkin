# Silent Wither hurt and death sounds

Silent Withers still emitted hurt and death sound packets through Pumpkin's shared LivingEntity sound calls. Vanilla 26.3 calls LivingEntity.makeSound and Entity.playSound, which checks isSilent before dispatching either sound. The earlier Silent NBT/firing/spawn correction did not guard these emitters.

The two existing hurt/death sound calls now check the entity's synchronized Silent state. Hurt knockback remains outside this new check. Damage calculation, health, death status, loot, cooldown logic, sound category, volume and pitch remain in their existing paths. The shared correction applies to all living entities; no shared method signature or plugin event changes. The affected callers include direct/contextual damage through players and mobs, and death handling. Actual plugin listeners and other mob families are outside this bounded live comparison.

Regression coverage is fixtures/wither-living-silent/cases.json and tests/check_wither_living_silent.py. Two trials each cover hurt/death for audible, Silent, toggled-Silent and removed-Silent Withers. A creative protocol 777 observer receives decoded sounds and death status from isolated scratch arenas. NoAI and frozen ticks isolate sound dispatch. Sheep-attributed attacks also verify damage and knockback: each nonlethal hit leaves 296.32 health and positive-X 0.4 motion; Silent must not suppress either. Death status must remain present in every lethal case. The command stream and fixture hash are compared across targets.

Before-fix comparison: official 26.3 passes 176/176 checks; campaign 69 baseline passes 168/176, with exactly 8 Silent/toggled hurt/death sound failures. All health, knockback, death-animation, flag-removal, observer, tick and cleanup checks pass. The current upstream source 44d881c32 still has both unguarded sound calls. This live baseline is the campaign binary rather than a separately built upstream binary.

Validation: all 447 pumpkin-core library tests, workspace formatting, core all-target/all-feature Clippy and debug server build passed under the shared Cargo lock, one job, no debug info/incremental compilation, and the required 5 GiB/no-swap/200% CPU scope. Patched Pumpkin and vanilla each pass 176/176 checks; baseline passes 168/176 with exactly eight sound-dispatch failures. All targets use identical command streams over 496 verified case ticks plus cleanup. Patched hurt velocities equal baseline exactly; muted bosses still lose health and send death status. Source, fixture, checker and copied-binary hashes are recorded; server/client logs have no ERROR, panic or uncaught thread-exception lines. This is focused world/packet regression coverage, without a synthetic Rust getter test. The existing proc-macro-error2 future-compatibility notice remains.
