# Execute positioned anchor reset

Based on upstream master `5b53f064af8708ba33fcaa533b81ca29a53a3310` (still current when rechecked). Vanilla Java 26.3 ExecuteCommand resets the entity anchor to feet after resolving explicit positioned coordinates. Pumpkin retained eyes, making subsequent local coordinates start above the intended position. The fix resolves coordinates first, then resets the copied source anchor. Positioned-as is unchanged, matching vanilla.

The regression uses the actual dispatcher parser and positioned modifier with absolute and relative coordinates, checks the resulting position and feet anchor, and checks the original source remains eyes. It failed against the unmodified upstream implementation with Eyes != Feet. After the fix, all four execute tests passed (Cargo exit 0). Commands: cargo test --locked -p pumpkin-core positioned_coordinates_reset_the_entity_anchor --lib before the fix, then cargo test --locked -p pumpkin-core command::commands::execute::tests --lib after it. Both used the shared build lock, one Cargo job, no incremental/debug info, 5 GiB memory/no swap and 200% CPU caps. The changed Rust file also passes rustfmt --check and git diff --check. Clippy and a full workspace test suite have not been run.

Vanilla was checked against its verified 26.3 server JAR using a local targeted decompilation (not included). A live two-repeat command probe summoned an armor stand at 2.5 64.25 2.5, executed anchored eyes positioned ~ ~ ~, and summoned a marker using local coordinates. Vanilla returned Test passed. Count: 1 for the marker at feet in both repeats. Live release Pumpkin rejects execute; it does not validate this patch. Current upstream removed RCON, and its baseline deployment was reverted by the provisioning lane because readiness could not be established. No source-fix live pass is claimed.

Open upstream positioned/entity-anchor searches were rechecked after testing and found no matching fix. Evidence remains in the live lab artifacts: christine-upstream-overlap.json, christine-upstream-anchor-test-before.log, christine-upstream-anchor-test-verify.log and its explicit exit-code JSON, and christine-anchor-vanilla-validation.json. No upstream PR or issue was opened.
