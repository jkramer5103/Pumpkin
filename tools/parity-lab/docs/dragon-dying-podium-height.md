# Dying dragon podium height

Dying flight resolved its target with WorldSurface at the top block's Y, falling back to Y=65 at the world minimum. Vanilla 26.3 DragonDeathPhase.doServerTick uses the bottom center of the first space above the MotionBlocking heightmap. Pumpkin now queries that map and adds one to its top-block coordinate, preserving the cached target and existing flight/death decisions.

In an isolated bedrock podium at Y=79, a fresh dying dragon at Y=89.5 starts dying in vanilla but remains at one health in baseline Pumpkin. At Y=69.5 the baseline starts dying while vanilla remains at one health. These are observable differences after one controlled tick, without relying on natural flight trajectory.

The persistent `dragon-dying-podium-height.json` fixture repeats both boundary cases, a continuing-flight control, a dandelion decoration that must not raise MotionBlocking height, and a NoAI control. Each summon is verified at 20 health before its one controlled tick. Vanilla selectors omit zero-health dragons, so death assertions reject any matching dragon with nonzero health, rather than requiring a zero-health corpse to be selectable. The initial exploratory fixture used that invalid assumption; its aggregate result is excluded.

Validation: all 479 `pumpkin-core --lib` tests, workspace formatting, `pumpkin-core --all-targets --all-features` Clippy and the debug server build passed under the shared Cargo lock with one build job, disabled debug info/incremental builds, MemoryMax=5G, MemorySwapMax=0 and CPUQuota=200%. The focused regression is the persistent executable server comparison fixture; no unit test duplicating coordinate arithmetic was added.

In two isolated arena trials, vanilla and patched Pumpkin pass 44/44 checks; baseline Pumpkin passes 40/44 with exactly the upper/lower bare-podium boundary failures in both trials. Each target advances 14 controlled ticks, with matching fixture/stimulus hashes, a connected headless player, stopped scratch servers and no logged ERROR/panic lines. Both Pumpkin saves complete. Vanilla's final-save completion marker was not observed within shutdown grace, although its process stop is verified. The patched source SHA-256 matches the passing Rust build, and the copied executable hash matches the arena run. Existing proc-macro-error2 future-compatibility and debug/development/offline-mode/native-access warnings remain.
