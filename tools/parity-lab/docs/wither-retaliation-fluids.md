# Wither retaliation fluid retention

Damaging an active Wither primes its block-breaking pulse. Pumpkin replaced nearby water, lava and seagrass with air; vanilla retains the fluid occupying the destroyed block. Seagrass therefore leaves source water instead of draining its cell.

`World::break_block` now uses its existing `fluid_state_from_block_state` conversion for the replacement. Dry blocks still become air and ordinary waterlogged blocks still leave source water. Existing plugin cancellation, loot, neighbor flags and break-effect handling stay in place. The same conversion also handles flowing/falling fluids and other aquatic plants; the live comparison covers only the four cases below.

The reference is Minecraft 26.3 `WitherBoss.customServerAiStep` calling `Level.destroyBlock`, which replaces the block with `getFluidState(pos).createLegacyBlock()`. Source and jar hashes, master refs, caller review and upstream overlap are recorded in the local assignment54 provenance artifact. The mob AI tracker is a lead; the verified call chain establishes this defect. Open PR4092 concerns the AI foundation, PR3859 block-entity cleanup and PR3826 ice breaking; none changes this replacement.

The regression fixture is `lab/examples/wither-retaliation-fluids.json`. One creative protocol client keeps an isolated loaded arena active. Bedrock seals the fluid cell on all six sides, preventing flow or refilling from hiding removal. Each source-water, source-lava, seagrass and dry-stairs row confirms setup, damage acceptance, pre-pulse retention after 19 ticks, replacement on tick 20, a broken stone control, intact bedrock and the boss position. `tests/check_wither_retaliation_fluids.py` validates captured reports, accepting exactly three fluid failures on the baseline.

Final comparison: vanilla and patched Pumpkin each passed 40/40 checks; baseline d0034b1cd passed 37/40, failing exactly the source-water, source-lava and seagrass fluid-retention checks. Each target completed 206 controlled ticks with identical fixture and gameplay hashes, successful cleanup and clean server/client logs. Pumpkin save/stop markers were verified. Earlier exploratory captures are excluded. All 444 core Rust library tests, workspace formatting, core Clippy with all targets/features and the debug server build passed under the shared Cargo lock and resource limits. Verified source and copied-binary hashes link the patched run to the Rust change.

Limitations: command-controlled damage and NoGravity isolate retaliation; this is no natural-fight or rendered-client proof. Initial block-particle behavior and the successful-break return value for unchanged pure fluids remain outside this patch. Fluid-only retaliation may still send the boss break event even when no block changes. A real client can inspect the sealed cell before and after damaging the boss; the water/lava must remain, seagrass must leave water, and the solid control must break after twenty ticks.
