# Sitting dragon breath radius

Pumpkin sitting breath starts with radius 3, shrinks with elapsed ticks, and grows by 0.5 whenever it affects an entity. Vanilla 26.3 uses a fixed radius of 5. Pumpkin therefore misses victims inside the intended footprint and can eventually damage victims outside it after crowd contacts.

`DragonSittingFlamingPhase.doServerTick` sets radius 5. `AreaEffectCloud` defaults both `radiusPerTick` and `radiusOnUse` to zero, and the sitting phase leaves them unchanged. The correction stays in `phase/sit_breathing.rs`: radius 5, radius-on-use zero, and reset the potion-oriented constructor's per-tick shrink to zero before spawning. Shared cloud and potion behavior are unchanged.

The regression fixture is `lab/examples/dragon-breath-radius.json`. Two isolated trials create a real sitting-dragon cloud, pause the emitting dragon and move it away. A sheep at distance 4 must take damage; a fresh sheep at distance 4.9 must still take damage when the emitted cloud has aged 80 ticks. Sheep at distance 5.5 must remain healthy, including after seven sheep contact the center. Every health query, entity-presence check and tick boundary is retained. This asserts damage eligibility rather than damage amounts.

Before the patch, vanilla passed 45/45 focused checks and the previous campaign binary passed 39/45. Pumpkin missed both inside victims and damaged the outside victim after crowd contacts in each trial. The final reference fixture uses identical stimulus commands and exact tick deltas on both servers, with a logged-in protocol-777 headless client. An initial fixture with trailing whitespace in predicate commands was excluded and corrected before the final comparison.

All 460 pumpkin-core library tests passed, as did workspace formatting, pumpkin-core Clippy with all targets/features, and the debug server build. All Cargo operations used the shared build lock, one job, disabled debug info/incremental, and the required memory/CPU limits. The existing proc-macro-error2 future-compatibility warning remains. The patched binary passed all 45/45 focused live checks, including both trials. Source/binary/fixture hashes, identical stimulus commands, exact tick deltas and client presence were verified. All three scratch processes stopped; both Pumpkin save completions were verified, while the vanilla final save completion marker was not observed. No errors or panics were found in the three console logs.

Fork master `65bca3f` is already an ancestor of this campaign branch. Upstream master `998c3f8` and the open dragon PRs were checked; PRs 3407 and 3661 address hitboxes, and PR 3835 addresses projectiles. None corrects this sitting-cloud footprint. No upstream changes were copied.

Limits: the fixture deliberately measures distances from each actual cloud center because placement is still different. Shared cloud damage falloff, vertical targeting, effect cadence, particles/owner, duration and natural sitting-phase cycles remain separate work. This is headless server-state evidence, with no rendered-client or whole-fight claim. For a visual check, a human must inspect the emitted cloud and attack footprint in an isolated arena with a real client.
