# Sitting dragon breath cleanup

A sitting dragon's breath cloud kept dealing damage after its breathing phase ended. Vanilla `DragonSittingFlamingPhase.end()` discards its own flame cloud. Pumpkin inherited the empty `Phase.end()` hook and never remembered the spawned cloud.

The dragon now records the cloud UUID on emission. The breathing phase takes and clears that reference on exit and removes the cloud through the existing world removal path. Same-phase assignments and NoAI pauses preserve it. Each dragon owns a separate reference; unrelated clouds are untouched. If the recorded cloud has already disappeared, the phase clears its reference without removing anything else (source reviewed; not separately exercised live).

The fixture `lab/examples/dragon-breath-cleanup.json` enters breathing phase 5 in an isolated arena, puts a stationary sheep at the actual cloud center, and observes its health. Before phase exit, both servers deal 3 damage. After resetting the sheep to 8 health and switching the dragon to phase 10, vanilla removes the cloud and preserves 8 health; the unpatched fork retains the cloud and deals another 3 damage. It also exercises exit to phase 7, same-phase and NoAI preservation, two dragons, and an unrelated cloud.
